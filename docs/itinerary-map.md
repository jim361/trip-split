# 일정·지도 기능 논의

[논의 홈](README.md) · **일정·지도** · [정산·영수증](settlement-receipts.md)

장소를 모아 날짜별 일정으로 배치하고, 일정 화면 위의 지도에서 이동 순서를 확인하는 흐름을 다룬다. 현재 기본안은 해외 도쿄 여행의 Google 연동을 먼저 검증하고, 같은 공통 계약으로 국내 NAVER 연동을 이어서 구현하는 것이다.

```text
여행 유형 선택 → 장소 저장 → 날짜별 일정 배치 → 지도에서 순서 확인 → 외부 길찾기
```

## 첫 배포 후보

| ID      | 기능                                                | 사용 상황·기대 결과                                           | 상태   | 회의 메모                                    |
| ------- | --------------------------------------------------- | ------------------------------------------------------------- | ------ | -------------------------------------------- |
| IT-01   | 국내는 NAVER, 해외는 Google을 자동 사용한다         | 사용자는 provider를 별도로 설정하지 않는다                    | 논의중 | Google 우선 구현, NAVER는 같은 계약으로 연결 |
| IT-02   | 장소 검색·지도 링크 붙여넣기·직접 입력을 지원한다   | 검색 결과가 없거나 링크 해석에 실패해도 장소를 저장할 수 있다 | 논의중 | 여행 provider에 맞는 검색 사용               |
| IT-03   | 공동 장소 보관함을 제공한다                         | 아직 일정에 넣지 않은 후보를 함께 모으고 수정·삭제할 수 있다  | 논의중 | 이름·주소·좌표·메모·원본 링크 저장           |
| IT-04   | 여행 기간의 날짜별 탭 또는 섹션을 제공한다          | 여러 날의 일정을 빠르게 전환한다                              | 논의중 | 선택 날짜를 URL로 공유할지 결정 필요         |
| IT-05   | 일정 항목을 추가·수정·삭제한다                      | 시간, 제목, 메모와 연결 장소를 관리한다                       | 논의중 | 시작·종료 시간 포함                          |
| IT-06   | 장소 없는 일정도 허용한다                           | 항공편, 체크인, 휴식과 단순 메모를 일정에 넣을 수 있다        | 논의중 | 지도에는 표시하지 않음                       |
| IT-07   | 일정 순서를 직접 바꾸고 시간순 정렬을 보조한다      | 사용자가 정한 실제 이동 순서와 지도 번호가 일치한다           | 논의중 | `order`와 시간 중 무엇을 우선할지 결정       |
| IT-08   | 일정 상단에 작은 지도를 두고 같은 화면에서 확대한다 | 지도 아래 일정을 이어서 보고 필요할 때만 크게 확인한다        | 논의중 | 확대 상태는 `?map=expanded`로 공유           |
| IT-09   | 선택 날짜의 장소를 번호 핀과 직선 동선으로 표시한다 | 실제 경로 계산 없이도 방문 순서를 이해한다                    | 논의중 | 날짜별 색상·자동 bounds 포함                 |
| IT-10   | 연속된 일정 사이를 외부 지도 길찾기로 연다          | NAVER 또는 Google 지도에서 대중교통·도보·차량 경로를 확인한다 | 논의중 | 앱 내부 경로 계산은 후속                     |
| IT-11   | 다른 멤버의 장소·일정 변경을 실시간 반영한다        | 단체 여행에서 같은 최신 일정을 본다                           | 논의중 | MVP 권한은 모든 멤버 editor                  |
| IT-12   | 모바일과 PC에서 같은 기능 구조를 사용한다           | 390px에서는 세로 흐름, PC에서는 넓은 패널로 확장한다          | 논의중 | 별도 모바일 페이지는 만들지 않음             |
| PREP-01 | 항공·숙소·교통·티켓 예약 정보를 모은다              | 예약 상태, 링크와 메모를 일정 옆에서 확인한다                 | 논의중 | `준비` 영역 유지 여부와 함께 결정            |
| PREP-02 | 여행 체크리스트를 제공한다                          | 출국 준비물과 공동 준비 작업을 확인한다                       | 논의중 | 개인/공용 항목 구분 여부 결정                |
| PREP-03 | 예약을 일정 항목과 연결한다                         | 항공편·숙소 예약 상세에서 해당 일정을 바로 찾는다             | 논의중 | 첫 배포에는 링크만 둘 수도 있음              |
